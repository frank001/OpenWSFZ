## What was checked and found sound

- **The vendored path is untouched.** `ftx_find_candidates` and `decode.c` have no diff. `ftz_find_candidates` with `thin` 0 returns `ftx_find_candidates` itself (so the cap, floor, heap and order are today's); with `thin` 1 it calls it with a cap equal to the whole grid (`ftz_grid_capacity` = 30 time offsets x `num_bins` x `time_osr` x `freq_osr`, a true upper bound: `decode.c:290-330` loops `time_offset` -10 to 19 and `freq_offset` below `num_bins - 7`), so the floor, the score and the position set are the vendored ones.
- **THIN is exactly the Architect's amended rule.** A merge sort by (score descending, lower frequency, earlier time: a total order, so the result never depends on stability), then one walk that drops a candidate only when an already KEPT candidate is within `+-freq_osr` frequency units and `+-time_osr` time units (inclusive: 6.25 Hz and 0.16 s on any grid, integer arithmetic, no float comparison) and stops at the cap. No two survivors can be inside the window by construction, and a chain keeps both ends. It replaces `ftx_find_candidates` at the round-0 and the residual-round call sites; the XC round runs through the same residual code, so it is covered. The probe's LOW search (cap 400, floor 0) stays on the vendored function, correctly (it is a diagnostic, not the decoder's list).
- **FINE is a zero-padded FFT, as the Architect specified.** `monitor.c`: `window_len` (0 = `nfft`) separate from `nfft`; `fft_norm = 2 / window_len` (today's 2-symbol normalisation); the FFT input is the **most recent `window_len` samples** (the tail of `last_frame`), windowed, zero-padded at the end, so the 2-symbol alignment is unchanged and every second bin equals today's. Lean sets `window_len` = 3,840 only when `freq_osr` > 2; classic never sets it (0 = `nfft`, the original loop). Sizes: `nfft` is 3,840 today and 7,680 at `freq_osr` 4, both inside `timedata[8192]` and `freqdata[4097]`; `monitor_process` now refuses an FFT beyond those bounds and clamps `src_bin` (not reachable today). `window` is allocated and freed at `window_len`; nothing else reads `window`, `fft_norm` or `nfft` outside `monitor.c`. There is one `monitor_config_t` for the cycle (`monitor_reset` for the residual's spectrogram), so every round and the XC round read the same grid.
- **Every candidate-to-physical conversion reads the waterfall's own oversampling.** The probe footprint (`:585-604`), the position conversions (`:656`, the CAND, LOW and `pos_f` / `pos_t` rows) use `wf->` / `mon.wf.`; the only `K_*OSR` left in `ftz_decoder.c` are the defaults for 0 and the `window_len` rule; `coherent_llr.c:417/490` are reached only from the separate `ft8_coherent_llr_at` / `ft8_extract_llrs_at` exports (classic and tests), not from lean (tier B goes through `cf_process_one` with physical frequency and time). Matches the Developer's grep list.
- **Parameters.** `ftz_params_t` v7 (`thin`, `time_osr`, `freq_osr`, one spare; 96 bytes); the entry copies a shorter caller struct into a zeroed local (`ftz_decode_cycle`, `struct_size` rule), so a v6 caller reads 0 = today's search; an invalid value returns the new `FTZ_ERR_PARAM` (-5) before anything is allocated; the managed wire struct and `LeanCycleParams` (`Thin`, `TimeOsr`, `FreqOsr`, all default off) match; `LeanCycleStats.ErrParam` added.
- **Probe rows** carry `time_sub` / `freq_sub` on CAND and LOW rows (64 to 72 bytes, the managed wire mirror and `LeanProbeRow` follow with defaulted fields, so existing constructors compile): what QA's arm-F first check reads.

## Minor notes (none blocks)

1. **Test (a) is self-referential:** it compares an explicit thin 0 / 2 x 2 call with the plain call of the same build, so it cannot show "byte-identical to `main`". 2. **Test (d)'s odd sub-position is the frequency one** (`freq_sub` 1); the time sub-position of the published candidate is even (2). The test asserts "odd time or odd frequency", which is what the spec's check needs; a half-hop-off signal landing on an even time sub-position is just the search choosing the better neighbour. No action.
