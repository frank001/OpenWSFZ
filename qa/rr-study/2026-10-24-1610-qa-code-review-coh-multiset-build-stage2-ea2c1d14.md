**Fix, any of:** (a) a fixture (synthetic, Q-prefix message) where V3 fails and two or more sets are CRC-valid at the candidate's anchor, found by a scan like the existing ones, with the assertion `row.Provenance == the lowest-numbered CRC-valid set` using `Ft8LibInterop.CohFallbackSetsAt` at the row's own anchor as the oracle; require at least one such fixture on each platform, as the existing tests do; or (b) assert `row.Provenance == CohFallbackSetsAt(...).WalkSet` for every attempted row of the existing winning fixtures AND one fixture with several valid sets.
