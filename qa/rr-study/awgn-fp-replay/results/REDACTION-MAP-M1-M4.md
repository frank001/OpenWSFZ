# NFR-021 redaction map -- AWGN-FP M1-M4 result CSVs

Same method as `results/REDACTION-MAP.md` (ROW 0's own redaction pass) -- imported from the project's own scanner (`qa/rr-study/nfr021_pre_merge_scan.py`), not reimplemented. Every token below is decoder output on a signal-free (S5) or signal-present (S1) offline replay, never injected truth -- verified against every render's own `truth.csv` `message_text` column before rewriting (see `redact_m1_m4_decodes.py`'s guard step).

Placeholders use an `M` infix (`<RDCTMnn>`) distinct from ROW 0's own `<RDCTnn>` placeholders so the two passes' tokens are never confused if both CSVs are read together. Deliberately NOT Q-prefix, for the same reason as ROW 0's map: a Q-prefix placeholder would be indistinguishable from a legitimately injected synthetic call and would corrupt a future `truth.csv` join.
